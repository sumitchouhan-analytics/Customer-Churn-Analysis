# Customer Churn Analysis

## About This Project

I created this project to analyze customer churn and understand why customers leave a service. I used Python, SQL, and data visualization to explore customer and subscription data.

## Tools Used
- Python
- Pandas and NumPy
- SQL and SQLite
- Matplotlib and Seaborn
- Jupyter Notebook

## What I Did
- Loaded data from a SQLite database.
- Cleaned and combined customer, subscription, and support data.
- Analyzed churn by plan type and contract type.
- Worked on churn rate, retention rate, and customer tenure.
- Created visualizations to understand churn patterns.

## Key Learning

This project helped me practice data cleaning, SQL queries, data analysis, KPI calculations, and visualization. I also learned how to use data to understand customer retention problems.
